# سلام

این پیش‌نمایش مارک‌داون برای فارسی، عربی و عبری است. متن از راست چیده می‌شود و قطعه‌های کد از چپ.

## فهرست

- مورد نخست
- مورد دوم
  - زیرمورد

## نقل‌قول

> نوشتار باید از سمتی شروع شود که خواننده انتظار دارد.

## کد

یک نام `inline` داخل جملهٔ فارسی می‌ماند، و بلوک زیر چپ‌به‌راست است.

```javascript
function greet(name) {
  return `Hello, ${name}`;
}
```
